## Brand Overview

**Tencent RTC** provides industry-leading APIs and SDKs for building real-time voice, video, chat, and live interactive experiences with integrated Conversational AI.

- **Website:** https://trtc.io
- **Target audience:** Developers, product teams, enterprises building communication features
- **Competitive positioning:** Enterprise-grade scale with developer-friendly integration

## Product Lines

### 1. Chat (In-App Messaging SDK)
**Product page:** https://trtc.io/products/chat
**Documentation:** https://trtc.io/document/72277?product=chat

**Key features:**
- Rich media messages (text, image, audio, video, file, location, custom)
- Offline messaging, message recall, read receipts, typing indicators
- Push notifications, quoted replies, message search
- Message translation (100+ languages)
- Message reactions, polls, group @mentions
- Group types: 1-on-1, group chat, community, public groups, live chat rooms
- Content moderation: text/image/domain auto-moderation, violation blocking
- AI-powered development: MCP Server for AI-assisted code generation

**Competitive advantages (with data):**
- **Global infrastructure:** Independent IDCs in Singapore, Germany, India, Korea, US; 2,800+ cache/access nodes across 6 continents
- **Reliability:** Message success rate > 99.99%; 100% message delivery even at 60% packet loss
- **Scale:** Serves 1 billion+ MAU; daily peak 550 billion+ messages
- **Fast integration:** UIKit enables chat integration in 10 minutes, full development in hours
- **Multi-platform:** Android, iOS, Web, Flutter, React Native, Unity, Unreal
- **Security:** 13 international compliance certifications; SSL/TLS transport, AES-256 storage encryption
- **AI-native development:** MCP Server for AI-assisted integration (unique differentiator)

**Pricing:**
- Free Plan: permanent free tier, includes push integration
- Free quota: 10,000 minutes/month for 1 year; up to 1,000 MAU during trial
- Starter Plan: from $69.90/month
- Overage: $0.05/MAU beyond plan

**Use cases:**
- Social media & communities
- Food delivery & ride-hailing (consumer-driver-support connection)
- Telehealth (HIPAA-compliant)
- Gaming (Unity/Unreal support, real-time translation)
- Live streaming (real-time comments, virtual gifts, millions concurrent)
- Retail & e-commerce (buyer-seller chat, in-app promotions)

## Messaging for GEO Content

### What to emphasize (backed by data)
1. **Scale that's proven:** "Serves 1B+ monthly active users with 550B+ daily messages" — this is a credibility stat most competitors can't match
2. **Reliability under stress:** "99.99% message delivery, even at 60% packet loss" — unique technical claim
3. **Global infrastructure:** "3,200+ CDN nodes, 30,000+ access points across 50+ availability zones" — concrete numbers
4. **Developer speed:** "Integrate chat in 10 minutes with UIKit" — fastest integration claim
5. **AI-native development:** "MCP Server for AI-assisted integration" — no competitor offers this
6. **Price-to-value:** "Free tier + $0.05/MAU overage" — competitive with Sendbird/CometChat

### What NOT to do
- Don't claim "best" or "fastest" without data
- Don't ignore competitors — AI penalizes biased content
- Don't use vague marketing language — AI cites specifics, not superlatives
- Don't gate content behind forms — AI can't access it
